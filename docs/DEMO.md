# 演示脚本

## 无密钥演示（约 3 分钟）

1. 按 README 启动工作台，点击“使用示例仓库”。示例仓库只会生成在本项目 `.data` 下。
2. 点击“生成执行计划”，说明目前是 DEMO，只走只读工具流程。
3. 点击“确认计划并执行”，展示工具名称、参数执行结果和事件顺序。
4. 打开 Diff 与验证证据，说明演示不会模拟修改成功或测试通过；顶部应保持“尚未验证”。

## 真实模型演示

1. 构建 runner 镜像，配置 `.env` 并切换 `DEMO_MODE=false` 后重启。
2. 使用示例 calculator 仓库，要求修复加法函数并通过回归测试。
3. 确认计划，观察读文件 → SHA256 校验写入 → pytest → Diff。
4. 对照原始仓库和任务 worktree，确认源目录没有被修改。
5. 说明 tests passed 与任务正确不是同义词，展示独立验收脚本。

没有真实 API 配置时，不录制或发布“模型已修复任务”的演示。
